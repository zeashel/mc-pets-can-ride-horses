# Pets Can Ride Horses

A minecraft datapack that allows nearest cat or wolf within a 5 block radius to ride horses with you (as pictured below).

[image/gif later]

- Requires the Invisible Acacia Boat resourcepack ([included in this repo](invisible_acacia_boat/)).
- Optional: I highly recommend using this mod with either Optifine or [EMF](https://modrinth.com/mod/entity-model-features) and [Fresh Animations resourcepack](https://modrinth.com/resourcepack/fresh-animations). This is not required but highly improves the animations of your pets sitting on the horse and removes the invisible water patch!
- Compatible with my [Immortal Pets datapack](https://github.com/zeashel/mc-immortal-pets).
